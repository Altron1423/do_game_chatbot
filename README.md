# Танковый чат

Многопользовательская игра на FastAPI с общей комнатой чата. Сервер хранит состояние только в памяти одного процесса; база данных и постоянное соединение с клиентами не используются.

## Запуск

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000` для игрового поля и общего чата.

Игра работает в одной общей комнате, число игроков и танков не ограничено. Браузер показывает поле и чат; отправлять сообщения и команды можно через терминальный клиент. Для регистрации отправьте `войти ИМЯ`, например `войти Анна`. Первый игрок запускает 15-секундный отсчёт. Раунд завершается после уничтожения всех танков.

Команды управления: `вверх`, `вниз`, `влево`, `вправо`, `выстрел`. Игрок также может зарегистрироваться запросом `POST /api/join` с JSON `{"name":"Анна"}`. Неактивный 30 секунд игрок передаёт танк боту.

## API

- `POST /api/join` — зарегистрировать игрока; JSON `{"name":"Анна"}`.
- `POST /api/messages` — отправить сообщение; JSON `{"sender":"Анна","text":"Привет"}`.
- `POST /api/commands` — отправить одну из пяти команд управления с тем же JSON-форматом.
- `GET /api/state?after=VERSION` — полное состояние игры; если версия не изменилась, запрос ждёт следующего события.

API-документация FastAPI доступна по `/docs`. Постоянного игрового тика нет: команды применяются сразу при получении, а таймерные события для отсчёта, ботов, бонусов и снарядов обрабатываются по ближайшему дедлайну. Браузер получает начальное состояние, затем держит long-poll запрос открытым и отправляет следующий сразу после события изменения комнаты.

Запустите терминальный клиент без параметров:

```sh
python terminal_client.py
```

Клиент использует адрес сервера из константы `SERVER_URL`, запрашивает имя и затем читает сообщения/команды из stdin. При успешной отправке клиент ничего не выводит; сетевые ошибки и ошибки сервера отображаются в stderr.

## Игровые правила

Карта — фиксированная 26×13 (в 2 раза шире исходной). Вода не является непроходимым препятствием: танки могут по ней двигаться, а снаряды проходят сквозь. Снаряды проходят через кусты, разрушают кирпич после двух попаданий и останавливаются о сталь и базу. Танки игроков добавляются без ограничения; боты появляются волнами, а после 30 секунд бездействия танк игрока переходит под управление бота. Бонус с вероятностью 30% появляется после уничтожения танка: звезда повышает уровень и лимит снарядов до двух, шлем защищает 8 секунд, часы замораживают остальные танки на 5 секунд.

Отсчёт до старта идёт в чате комнаты: «Раунд начнётся через 15 с», затем обратный отсчёт «Старт через 5/3/2/1 с» и «Старт! Раунд начался.» после завершения.

Сообщения и состояние доступны только в памяти процесса; чат хранит последние 200 сообщений комнаты для браузерного отображения. При перезапуске сервера комнаты и раунды теряются. Запуск нескольких рабочих процессов не поддерживается.
